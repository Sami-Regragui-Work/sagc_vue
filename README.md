# sagc_vue

Vue.js frontend for the Authentication System and Profile Management project.

**Backend API Repository:** [sagc_api](https://github.com/Sami-Regragui-Work/sagc_api)

## Project setup
```
npm install
```

### Compiles and hot-reloads for development
```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Lints and fixes files
```
npm run lint
```
